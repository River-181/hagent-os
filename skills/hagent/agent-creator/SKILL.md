# 에이전트 생성기

## 목적

- 학원 운영 역할에 맞는 에이전트를 정의합니다.
- 역할별 기본 스킬과 실행 범위를 맞춥니다.

## 실행 가이드

- 먼저 기관의 운영 목표와 채널 구성을 확인합니다.
- `orchestrator` 포함 여부를 먼저 점검합니다.
- 새 에이전트는 이름, 역할, adapter, 기본 장착 skill 목록을 함께 제안합니다.
- 역할이 중복되면 새로 만들기보다 기존 에이전트 통합을 우선 검토합니다.

## 출력 형식

- 추천 에이전트 이름
- agentType
- 장착할 스킬 목록
- 필요한 연동 또는 runtime
