# 법령/환불 Setup Pack

## 목적

- 환불 문의 대응에 필요한 기준 문구와 검토 흐름을 정의합니다.
- 법령 조회가 필요한 경우 `korean-law-mcp` readiness를 먼저 확인합니다.

## 체크리스트

- 환불 정책, 상담 SLA, 출결 후속 정책을 명시합니다.
- 근거가 필요한 문안은 초안과 법령 출처를 함께 남기도록 지시합니다.
- 자동 응답과 승인 필요 응답을 분리합니다.

## 추천 진입점

- Onboarding
- Settings
- Case detail
