# 환불 계산기

## Use This Skill When

- 환불 가능 금액을 규정 기준으로 계산해야 할 때
- 민원 대응 전에 계산 근거와 설명 문구를 같이 준비해야 할 때

## Required Inputs

- 등록 과정과 결제 총액
- 수업 시작일과 현재 날짜
- 실제 수강/제공된 회차
- 환불 규정 또는 학원 정책 문서
- 예외 사유와 특약 여부

## Preflight

- 대상 조직과 현재 작업 컨텍스트를 먼저 확인합니다.
- 기존 케이스, 문서, 학생, 일정 중 무엇이 정본인지 확인합니다.
- 추가 runtime 요구사항이 없더라도 실제 발송/동기화 전에는 연결 상태를 다시 확인합니다.

## Source of Truth

- 환불 계산은 기관 환불 정책과 실제 결제 이력이 정본입니다.
- 정책과 실제 이력이 충돌하면 정책 문서 우선으로 보고 충돌을 표시합니다.

## Workflow

- 정책 기준일과 실제 제공분을 먼저 분리합니다.
- 총 결제액, 차감 항목, 환불 가능 금액을 단계별로 계산합니다.
- 정책상 해석이 갈리는 부분은 가정으로 분리합니다.
- 숫자 표와 설명 문안을 함께 만듭니다.

## Decision Rules

- 규정 문서가 없으면 확정 계산 대신 추정 범위만 제시합니다.
- 환불 금액은 항상 차감 근거와 함께 보여줍니다.

## Output Contract

- 계산 근거
- 중간 값
- 최종 결과
- 가정 및 누락값

## Failure Handling

- 결제 이력이나 정책 문서가 없으면 확정값을 내지 않습니다.
- 법적 해석이 필요한 경우 법령 조회 또는 사람 검토를 요구합니다.

## Guardrails

- 확인되지 않은 사실을 실행 완료처럼 말하지 않습니다.
- 외부 발송, 환불, 일정 변경처럼 운영 영향이 큰 작업은 approval 필요 여부를 먼저 표시합니다.
- integration이 없거나 degraded면 수동 fallback과 다음 조치를 같이 적습니다.

## Done When

- 최종 금액과 차감 근거가 함께 제시됩니다.
- 가정과 누락값이 분리됩니다.

## Runtime Fit

- Recommended agents: `finance`, `complaint`
- Adapter compatibility: `claude_local`
- Locale: `ko-KR`
