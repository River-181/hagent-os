# 채널 연결 Setup Pack

## 목적

- Kakao, Telegram, SMS 같은 운영 채널이 실제로 연결 가능한지 확인합니다.
- 인바운드 라우팅과 아웃바운드 승인 흐름을 정리합니다.

## 체크리스트

- 주 채널이 최소 1개 이상 활성화되어 있는지 확인합니다.
- 채널별 display name, inbound purpose, routing priority를 기록합니다.
- outbound 발송은 승인 흐름이 필요한지 여부를 분리합니다.

## 추천 진입점

- Onboarding
- Settings
- Agent detail
