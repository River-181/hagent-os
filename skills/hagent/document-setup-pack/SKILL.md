# 문서 자동화 Setup Pack

## 목적

- HWPX 처리 가능 여부와 출력 경로를 미리 확인합니다.
- 공지문, 승인 문서, 상담 요약 같은 산출물 템플릿 사용 기준을 맞춥니다.

## 체크리스트

- `hwpx-cli` 또는 대체 문서 엔진이 준비되어 있는지 확인합니다.
- 문서 산출물의 저장 위치와 케이스/프로젝트 연결 기준을 정합니다.
- 템플릿 기반 생성물은 초안/최종본 상태를 구분합니다.

## 추천 진입점

- Onboarding
- Project detail
- Documents
