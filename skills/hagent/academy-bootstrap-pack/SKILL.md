# 학원 온보딩 Bootstrap Pack

## 목적

- 기관 기본 정보와 운영 목표를 정리합니다.
- 채널, 정책, 데이터 가정, starter team을 최소 입력으로 준비합니다.
- setup project와 starter case가 바로 생성될 수 있도록 기준을 맞춥니다.

## 구성

- complaint-classifier
- korean-tone-guide
- schedule-manager
- student-360-view
- student-data-import
- kakao-channel
- google-calendar-mcp

## 실행 가이드

- 기관명, 목표, 환불/상담/출결 정책을 먼저 확보합니다.
- Kakao 또는 Telegram 같은 실제 인바운드 채널을 하나 이상 지정합니다.
- starter team은 `orchestrator`를 포함하도록 구성합니다.
- setup project에는 민원, 일정, 정책 확인용 starter case를 함께 만듭니다.

## 추천 진입점

- Onboarding
- Settings
- Agent detail
